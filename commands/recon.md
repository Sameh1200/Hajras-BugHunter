# /recon

Hajras recon workflow command.

Run structured external recon: subdomain enumeration, live probing, port discovery, URL collection, and initial surface mapping.

## Flow
1. Scope confirmation
2. Passive subdomain sources
3. DNS resolution
4. HTTP probing
5. Port sampling
6. Crawl / archive URLs
7. Summarize attack surface for hunt phase

Use with tools from HajrasSkillsToolsMCP (subfinder, httpx, dnsx, naabu, katana, gau, nuclei).
